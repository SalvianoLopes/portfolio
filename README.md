## 🚀 Case em Destaque: FreteHub (Ydècory)

**Centralização da cotação de fretes entre transportadoras, cálculo por cubagem, acompanhamento de entregas e controle financeiro operacional.**

* **Contexto & Desafio:**  
  Operação logística com alto volume de cotações manuais fragmentadas por e-mail e planilhas, gerando lentidão no cálculo de peso cubado, falta de padronização nas tabelas tarifárias de transportadoras e ausência de visibilidade em tempo real sobre status de notas fiscais e custos de frete.

* **Solução de Engenharia:**  
  Plataforma web integrada para automatizar o ciclo completo de fretes:
  * Motor de cálculo comparativo multitransportadoras com regras tarifárias dinâmicas.
  * Cálculo logístico automatizado de peso real vs. peso cubado.
  * Acompanhamento de entregas e status de notas fiscais com filtros operacionais.
  * Painel financeiro para conciliação de fretes e histórico de custos.
  * Controle de acesso por perfil de usuário.

* **Stack de Referência:**  
  * **Frontend:** Next.js, React, Tailwind CSS
  * **Backend & Dados:** Supabase, PostgreSQL
  * **Deploy & Infra:** Vercel

* **Prévia Ilustrativa:**  
  *Ilustração estática com dados fictícios, sem cálculo ou integração com produção. A descrição técnica detalhada e a stack de referência precisam ser conferidas no repositório real do FreteHub, não incluído neste pacote.*

## 🏃 Como Executar o Portfólio Localmente

O portfólio é construído em arquitetura estática leve, garantindo velocidade máxima de carregamento e facilidade de manutenção sem necessidade de build complexo.

### Opção 1: Com Node.js / npx
```bash
# Clone o repositório
git clone https://github.com/SalvianoLopes/portfolio.git
cd portfolio

# Inicie um servidor local
npx serve .
# ou
npx http-server .
```
Acesse `http://localhost:3000` (ou a porta indicada no terminal).

### Opção 2: Com Python
```bash
# Dentro da pasta do projeto:
python -m http.server 8000
```
Acesse `http://localhost:8000`.

### Opção 3: Direto no Navegador
Abra o arquivo `index.html` em qualquer navegador moderno.
